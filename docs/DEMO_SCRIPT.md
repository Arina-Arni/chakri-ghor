# Demo video script (5–7 minutes)

Record at 1280×800 with the browser zoomed to 110%. Keep a phone-width window (360 px) ready for the mobile shots. Use the seeded accounts, which are not shown on screen.

| Time | Scene | What to show and say |
|---|---|---|
| 0:00–0:30 | **Problem** | Government circulars are scattered across hundreds of sites; seekers find out late, can't tell if they qualify (age on a specific date, district quotas), and lack an English ATS CV. *চাকরি রাডার* puts it all in one Bangla-first place. |
| 0:30–2:00 | **Seeker journey (mobile)** | Landing → AI search `খুলনায় সরকারি অফিস সহকারী` → chips + results → open the DC Khulna circular → **যোগ্যতা যাচাই** (exact age on the reference date, district rule) → **রিজিউমে সাজান** (ATS score, AI before/after changes, PDF) → add to tracker → move to *আবেদন করেছি*; try *নির্বাচিত* to show the refusal. Show the deadline reminder in notifications. |
| 2:00–3:15 | **Admin ingestion (A07)** | `/admin/ingest` → upload `samples/notice-text.pdf` → timeline: text extracted → AI extraction → normalize (Bangla dates and districts) → dedupe → tags → draft → **review gate waits** (confidence and verification rules) → approve in `/admin/review` → publish → notify; the seeker gets *নতুন মিল*. Upload `notice-text-copy.pdf` → **duplicate**. |
| 3:15–4:15 | **A06 live fault injection** | `/admin/ai-health` → enable *AI সার্চ → টাইমআউট* (only for this admin, 15 min, audit-logged) → AI search still returns results via the rule-based parser in under 4 s with a Bangla notice → back to AI health: the failure is logged with attempts and latency; after 5 failures the breaker is **open**; switch to *ভাঙা JSON* to show the repair attempt; turn it off and the half-open probe closes the breaker. Mention cache, quotas and the hallucination guard. |
| 4:15–5:15 | **A07 failure and resume** | Ingest new text with *fail at notify_matches* → earlier steps green, `notify_matches` retried 3× → run failed → **Retry failed step** → only that step runs → completed; one circular, no duplicate notifications. Briefly: leases (a crashed worker's step is reclaimed), batch cursor, corrigendum branch, compensation on cancel. |
| 5:15–6:15 | **Edge cases** | IDOR: change a resume id in the URL → 404. Double-click Apply → one card. Conflicting edit in two tabs → conflict dialog. Guest AI quota → Bangla 429 message with the reset time. |
| 6:15–7:00 | **Architecture and limitations** | The README architecture diagram: Next.js on Vercel, Supabase (Postgres, Auth, Storage), Gemini behind one client, Resend through an outbox, pg_cron → worker/scheduler. Tests: 300+ unit, 50+ integration on real Postgres, CI. Limitations: no scraping, mock payments, scanned documents need Gemini. Next: employer portal, PWA, real payment providers. |
