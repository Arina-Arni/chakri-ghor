# Demo video script (5–7 minutes)

Record at 1280×800 with the browser zoomed to 110%. Keep a phone-width window (360 px) ready for the mobile shots. Use the judges' test accounts (a seeker and an admin). Never show passwords, `.env.local` or the Vercel and Supabase settings on screen.

**Before recording**

- **Live site:** it is deployed from `main` with `FAULT_INJECTION_ALLOWED=true`, and `npm run db:cron` has been run (README → Deployment).
- **Gemini quota:** record after about 14:00 Bangladesh time (08:00 UTC), when Gemini's free daily quota has reset. One take uses roughly 10–15 AI calls.
- **A real circular PDF:** download one open government circular from `alljobs.teletalk.com.bd` that is **not on the site yet**. Everything approved in review goes live to real users.
- **Sample PDFs:** the files in `samples/` are fictional. Use them only for the failure scene, and **reject** them at review so they never go live. Auto-publish is off, so every ingested circular waits for review.

| Time | Scene | What to show and say |
|---|---|---|
| 0:00–0:30 | **Problem** | Job circulars are scattered across hundreds of government sites and employers' career pages. Seekers find out late, can't tell whether they qualify (age on a specific date, district quotas), and lack an English ATS CV. *চাকরি রাডার* puts it all in one Bangla-first place. World Problem Solver track; advanced challenges A06 and A07. |
| 0:30–2:00 | **Seeker journey (mobile)** | Landing → AI search `ঢাকায় সরকারি অফিসের চাকরি` → chips + results → open a real government circular with an age limit (for example *ডাক অধিদপ্তর*) → **যোগ্যতা যাচাই** (exact age on the reference date, district rule) → **রিজিউমে সাজান** (ATS score, AI before/after changes, PDF) → **ট্র্যাকারে যোগ করুন** → move to *আবেদন করেছি*; try *নির্বাচিত* to show the refusal. Open a private job (for example a BRAC post) to show the official apply link. If a tracked job closes within 72 hours, show its reminder in notifications. |
| 2:00–3:15 | **Admin ingestion (A07)** | `/admin/ingest` → upload the real circular PDF → timeline: text extracted → AI extraction → normalize (Bangla dates and districts) → dedupe → tags → draft → **review gate waits** → approve in `/admin/review` → publish → notify matching seekers. Upload the same PDF again → **duplicate**, with a link to the first run. |
| 3:15–4:15 | **A06 live fault injection** | `/admin/ai-health` → enable *AI সার্চ → টাইমআউট* (only for this admin, 15 min, audit-logged) → AI search still returns results via the rule-based parser within 4 s, with a Bangla notice → back to AI health: the failure is logged with attempts and latency; after 5 failures the breaker is **open**; switch to *ভাঙা JSON* to show the repair attempt; turn it off and the half-open probe closes the breaker. Mention the model fallback, cache, quotas and the hallucination guard. |
| 4:15–5:15 | **A07 failure and resume** | Upload `samples/notice-text.pdf` (or paste a circular's text). Under *Advanced*, choose **ড্রাফট তৈরি** (`create_draft`) as the step to fail → the earlier steps are green, `create_draft` shows 3 attempts, the run is **ব্যর্থ** → **আবার চেষ্টা করুন** → only that step runs, the draft is created once and the run waits at review → **reject** it in `/admin/review` (fictional data never goes live). Briefly: leases (a crashed worker's step is reclaimed), the `notify_matches` batch cursor, the corrigendum branch, and compensation on cancel. |
| 5:15–6:15 | **Edge cases** | IDOR: change a resume id in the URL → 404. Double-click **ট্র্যাকারে যোগ করুন** → one card. Edit the profile in two tabs → conflict dialog. Guest AI quota → Bangla 429 message with the reset time. |
| 6:15–7:00 | **Architecture and limitations** | Show the README architecture diagram: Next.js on Vercel; Supabase for Postgres, Auth and Storage; Gemini behind one client; Resend through an outbox; pg_cron → worker and scheduler. Tests: 340+ unit and about 60 integration tests on real Postgres, all run in CI. Limitations: no scraping; private jobs only from employers' official pages; mock payments; Gemini free-tier quota; scanned documents need Gemini. Next: employer portal, PWA, real payment providers. |
